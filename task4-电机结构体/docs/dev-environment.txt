【1】CPU内部资源
	CPU型号        : STM32F107VCT6 / ARM 32-bit Cortex-M3
	主频           : 72MHz
	Flash          : 256 KB
    SRAM           : 64 KB
	定时器          : 10个
	UART           : 5个
	SPI            : 3个 (2个可复用为I2S)
	I2C            : 2个
	ADC            : 3个独立的12位ADC
	CAN            : 2个 CAN 2.0B


【2】开发工具
    【仿真器】 --- 非标配，可自行购买
	- ST-LINK V2 仿真器: ST公司开发的仿真器，可以下载程序和调试跟踪程序。支持STM8和STM32。

    【开发软件】
	- 编译环境 KEIL 的 AC5
               TRAE 的 EIDE
			   VScode 的 EIDE


【3】外部例程文件夹说明
├─Drivers :   
│  ├─Start :   启动文件和core文件
│  └─Library : 标准库代码
│
├─Inc      :  这里存放用户任务程序相关头文件
│  └─bsp  :  外设模块底层驱动头文件
│
├─Readme   :  工程相关说明
│
└─Src      :  这里存放用户任务程序C语音源文件
    └─bsp  :  外设模块底层驱动源文件

【4】工程中源代码虚拟文件说明

Keil编译环境
└─YS-F1PRO                        : Target名称
   ├─Application/MDK-ARM          : 启动文件(汇编源程序)
   ├─Application/User             : 存放 main.c 以及用户用用程序
   ├─Drivers/Core                 : 存放芯片驱动
   ├─Drivers/Library              : 存放标准库  
   ├─bsp                          : 板级支持包，存放模块底层驱动函数  
   └─Readme                       : 工程说明文档，仅限txt文件


【5】C编译器中的预定义宏 （在工程设置中更改）
	USE_STDPERIPH_DRIVER        - 增加这个符号表示使用ST公司的标准外设库驱动
	STM32F10X_CL                - 增加这个符号表示芯片大小规格选择
